# Замер в Вордстате: протокол, ошибки, запасные пути

## Как это устроено

Страница wordstat.yandex.ru получает данные запросом `POST /wordstat/api/getTable` с куками
залогиненного пользователя. JS из `kw.py js` (замер) и `kw.py audit` (проверка двойного
смысла) вызывает тот же запрос прямо из вкладки, поэтому:

- весь список меряется одним выражением `(фраза 1|фраза 2|…) -минус1 -минус2`; проверено до
  22 500 символов и 2 500 слов — итог точный (объединение, а не сумма); категории меряются
  такими же выражениями в том же запросе;
- ответ — «Общее число запросов» (то же число, что в шапке таблицы Вордстата), топ строк
  «Запросы со словами» и «Похожие» за последние 30 дней, все устройства;
- один запрос — доли секунды; пачка «список + категории + пробы» — несколько секунд;
- аудит (`kw.py audit`) ничего не записывает: он печатает строки каждой фразы с флагами
  маркеров, решение по фразе принимает агент (`kw.py checked` / `rm` / `minus`).

`javascript_tool` обрезает длинный ответ, поэтому полный JSON кладётся в `<article id="kw-result">`
на странице, а читается через `get_page_text` — тот отдаёт именно этот блок.

## Последовательность (Claude in Chrome)

1. `KW js <проект> [--probe "выражение" ...]` — пишет `pending.json` с номером запроса `rN`,
   печатает ссылку и код.
2. `tabs_context_mcp`. Если в группе вкладок нет Вордстата — `navigate` по ссылке из вывода
   (в ней `region=<id>`: по названию региона на странице `record` сверяет id).
   Регион сверяется один раз на проект; дальше подойдёт любая вкладка Вордстата.
3. `javascript_tool`, action `javascript_exec`, текст — код между `---8<---` целиком.
   Код начинается с `await (async () => {` — так инструмент дожидается результата.
4. `get_page_text` той же вкладки.
5. `KW record <проект>` — вывод `get_page_text` целиком в stdin (heredoc `<<'EOF'`) или файлом
   через `--in`. Заголовок `Title:/URL:` можно не вырезать — `kw.py` сам найдёт JSON.

Каждый выполненный замер записывается через `record` СРАЗУ, до любых изменений списка
(`add`/`rm`/`minus`): счётчик запросов `rN` растёт при генерации кода, и незаписанный замер
потом не примется («ждём rN+1»). Порядок захода шага 4 всегда: record → add → checked → js.

Пробы (`--probe`) принимают синтаксис Вордстата: `"бизнес школа"` (ровно эти слова),
`!бизнес`, `+на`, `[из москвы в сочи]`, `(а|б) в`, `-минус`. Группа всегда меряется простым
OR без операторов — так же, как фразы потом работают в VK Ads.

## Ошибки

| Симптом | Причина | Что делать |
|---|---|---|
| `ОШИБКА: это не вкладка wordstat.yandex.ru` | JS выполнен не в той вкладке | `navigate` на ссылку из `kw.py js`, повторить JS |
| `HTTP 401/403`, ответ ведёт на passport.yandex | не залогинен | попросить пользователя войти в Яндекс в этом Chrome, затем повторить |
| `не JSON (проверка на робота?)` | Яндекс показал капчу | попросить пользователя открыть вкладку и пройти проверку самому; повторить JS. Капчу не проходить |
| `record`: «это результат r4, а ждём r5» | прочитан старый блок или выполнен старый код | выполнить свежий код из последнего `kw.py js`, снова `get_page_text` |
| `record`: «регион ещё не сверен» | вкладка открыта не с `region=` проекта | открыть ссылку из `kw.py js`, повторить JS |
| `record`: «регион N называется «X»» | в карточке неверный id | `KW region Название`, затем `KW card <проект> --region-id N --region Название` |
| `record`: «Вордстат счёл выражение некорректным» | пробa с битым синтаксисом | исправить пробу; группа из `kw.py` всегда корректна |
| `javascript_tool` вернул `{}` | код изменён и не ждёт промис | передать код без правок |
| Итог группы 0 при живых фразах | слишком узкие/редкие формулировки или минус-слово режет всё | посмотреть пробы крупнейших фраз, проверить минус-слова |
| `record`: «контрольная сумма не сходится» | опечатка при переносе JSON в inbox-файл | найти битый блок пофрагментными хэшами (ниже), поправить только его |

После ошибки ничего не пересчитывать вручную и не переносить старое число на новый состав:
новый `kw.py js` → новый замер.

### Чек-сумма не сошлась: как найти опечатку

При ручном переносе большого JSON теряется строка или символ — чек-сумма это ловит, но не
говорит где. Не перепечатывать всё заново: сверить хэш каждого блока `results[i]` в файле и
на странице — битый блок найдётся за один проход, чинится точечным `Edit`.

Хэши файла (python):
```python
import json, sys
sys.path.insert(0, r'<папка скила>/scripts')
from kw import fnv1a
d = json.load(open(r'<проект>/inbox.json', encoding='utf-8'))
rk = lambda rows: ';'.join(f'{t}:{n}' for t, n in (rows or []))
for r in d['results']:
    canon = '|'.join([r['id'], r['h'], r.get('error') or '', str(r.get('total','')),
        '1' if r.get('invalid') else '0', str((r.get('period_ms') or {}).get('endDate','')),
        rk(r.get('popular')), rk(r.get('similar'))])
    print(r['id'], fnv1a(canon))
```

Хэши страницы (`javascript_tool` в той же вкладке):
```js
(() => {
  const fnv = (s) => { let h = 0x811c9dc5; for (const b of new TextEncoder().encode(s)) h = Math.imul(h ^ b, 0x01000193) >>> 0; return h.toString(16).padStart(8, '0'); };
  const rk = (rows) => (rows || []).map(([t, n]) => `${t}:${n}`).join(';');
  const out = JSON.parse(document.getElementById('kw-result').textContent);
  return out.results.map((r) => `${r.id} ${fnv([r.id, r.h, r.error || '', r.total ?? '', r.invalid ? 1 : 0, (r.period_ms && r.period_ms.endDate) || '', rk(r.popular), rk(r.similar)].join('|'))}`).join(', ');
})()
```

Несовпавший id — битый блок; вытащить его со страницы отдельно
(`JSON.stringify(out.results.find(x => x.id === 'pN').popular)`), сравнить с файлом, вставить
пропавшую строку. Обычно теряется одна строка `["текст",N]` в середине длинного массива.

## Регионы

`KW region Название` ищет в `scripts/regions.txt` (регионы России из выбора региона
Вордстата: id, название, родитель). Понимает `спб`, `мск`, `екб`, `нск`, `рф`. Нет в
справочнике — выбрать регион в фильтре Вордстата и взять число из адреса (`region=...`).
Город и его область — разные регионы: «Москва» = 213, «Москва и область» = 1.

## Запасной путь без Claude in Chrome

Если инструментов Chrome нет, но пользователь может сам открыть Вордстат:

1. Пользователь открывает ссылку из `kw.py js` в своём браузере (залогинен в Яндекс).
2. F12 → Console → вставляет код между `---8<---` целиком, Enter.
3. В той же консоли: `copy(document.getElementById('kw-result').textContent)` — JSON в буфере.
4. Пользователь вставляет JSON в чат; дальше как обычно — `KW record`.

Встроенная панель браузера Claude (не Chrome) подходит так же, но в ней пользователь должен
сам войти в Яндекс.
