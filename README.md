# vk-ads-keywords

Семантика для VK Ads под названную тему — до **15 000+ реальных запросов Вордстата** по
нужному городу — **без Директа, без платных сервисов и без прогнозных цифр**. Скилу
достаточно строки вида «клуб миллионеров, Владивосток» или «антон назаров, нижний
новгород»: он задаёт короткий бриф одним блоком (аудитория оффера, город или РФ, цель,
границы — широкие пласты и бренды конкурентов), а дальше сам: ресёрчит оффер и похожие
офферы в сети, подбирает фразы по категориям, меряет спрос, чистит мусор и добирает объём
пластами до цели. На каждый вопрос брифа есть дефолт — ответ «сам реши» превращает запуск
в полностью автономный.

Ключевой приём: весь список меряется **одним OR-выражением** (`(ф1|ф2|…) -минус…`) через
внутренний запрос Вордстата из залогиненной вкладки Chrome — точное объединение без двойного
счёта пересечений, сотня фраз за секунды (проверено до 22 500 символов в выражении). Каждая
фраза до попадания в итог проходит **аудит двойного смысла по её реальной выдаче**: «уроки
французского» — это сериал, «клуб первых» — фильм и свингер-клубы, «айти школа» —
электронный дневник. Такое ловится только глазами по строкам, и скил это делает сам.

Кросс-агентный: одна методичка (`AGENTS.md`) работает и в **OpenAI Codex**, и в
**Claude Code**. Разница одна: агент с браузером, где пользователь залогинен в Яндекс,
меряет Вордстат сам; агент без него (типичный Codex) отдаёт готовый JS пользователю —
тот вставляет его в консоль F12 и возвращает JSON. Оба пути описаны в методичке.

Проверенные прогоны (30 дней, город, автономно от одной строки запроса):

| Тема | Город | Итог | Фраз | Категорий |
|---|---|---|---|---|
| Клуб миллионеров (фин. рост) | Владивосток | 19 496 | 133 | 11 |
| Осознанная Меркантильность (вход в IT) | Нижний Новгород | 15 095 | 61 | 6 |

## Что внутри

| Файл | Назначение |
|---|---|
| `AGENTS.md` | Кросс-агентная методичка (Codex подхватывает автоматически): конвейер, оба пути замера (A — свой браузер, B — пользователь-курьер через F12), команды `kw.py`. |
| `SKILL.md` | Обёртка Claude Code: тот же конвейер с именами его браузерных инструментов (`mcp__claude-in-chrome__*`). |
| `prompts/vk-ads-keywords.md` | Готовый Codex-промпт для слэш-команды `/vk-ads-keywords`. |
| `references/selection-rules.md` | Правила категорий, мусора, двойного смысла и **лестница пластов** — как город добирает 15к (ядро → тематический интерес → инструменты аудитории → события/конкуренты). |
| `references/wordstat.md` | Протокол замера, таблица ошибок (капча, лимит, битый перенос JSON), запасной путь без Chrome. |
| `scripts/kw.py` | Машина состояния проекта: фразы, категории, минус-слова, замеры с чек-суммами, аудит-гейт, экспорт. Только stdlib. |
| `scripts/wordstat_batch.js` / `wordstat_audit.js` | Шаблоны JS для пакетного замера и аудита во вкладке Вордстата (ретраи, защита от троттлинга, FNV-чек-сумма результатов). |
| `scripts/ru_stem.py` | Русский Snowball-стеммер: дубли и поглощение фраз считаются как в Вордстате. |
| `scripts/regions.txt` | Справочник id регионов РФ в Вордстате. |
| `scripts/test_kw.py` | 15 юнит-тестов: `python scripts/test_kw.py`. |

## Установка

Везде нужны: Python 3.9+ (только стандартная библиотека, API-ключей нет) и вход в Яндекс
в браузере пользователя (wordstat.yandex.ru открывается без логина).

### OpenAI Codex

**Вариант А — работать внутри репо (проще всего).** Склонируй репо и запускай Codex из
его папки: он автоматически прочитает `AGENTS.md` и будет следовать конвейеру.
```bash
git clone https://github.com/bratz121/vk-ads-keywords-skill.git
cd vk-ads-keywords-skill
codex "собери семантику VK Ads: клуб миллионеров, Владивосток"
```
У Codex нет браузера с твоим логином, поэтому замер идёт путём B: агент отдаёт ссылку и
готовый JS, ты вставляешь его в консоль F12 открытого Вордстата, затем
`copy(document.getElementById('kw-result').textContent)` — и возвращаешь JSON в чат.
Пара таких заходов на весь проект.

**Вариант Б — глобальная слэш-команда `/vk-ads-keywords`.** Скопируй промпт в каталог
пользовательских промптов Codex:
```bash
mkdir -p ~/.codex/prompts
cp prompts/vk-ads-keywords.md ~/.codex/prompts/vk-ads-keywords.md
```
Дальше в любом проекте: `/vk-ads-keywords антон назаров, нижний новгород`. Промпт
ссылается на методичку — держи склонированный репо под рукой или укажи агенту путь до
`AGENTS.md`.

### Claude Code

Скопируй папку целиком в каталог скилов — она уже готовый скил:
```bash
git clone https://github.com/bratz121/vk-ads-keywords-skill.git
cp -r vk-ads-keywords-skill ~/.claude/skills/vk-ads-keywords
```
Windows: `C:\Users\<имя>\.claude\skills\vk-ads-keywords`. Скил подхватится в новой сессии.
Дальше `/vk-ads-keywords <тема>, <город>` или просто «подбери ключевые фразы для VK Ads
под …». С расширением **Claude in Chrome** (вход в Яндекс в этом Chrome) агент меряет
Вордстат сам — путь A; без расширения работает тот же путь B, что и в Codex.

## Что получается на выходе

Папка проекта `kw-research/<имя>/`:

- `export/keywords.txt` — все фразы (копируются в VK Ads как есть);
- `export/категория-*.txt` — по файлу на категорию: для РФ — отдельные аудитории, для
  города — чтобы резать слабые пласты ставкой;
- `export/minus.txt` — общие минус-слова;
- `export/report.md` — отчёт: числа категорий, что вычищено и почему, статус цели;
- `state.json` + `evidence/rN.json` — всё состояние и сырые ответы Вордстата: каждое число
  в отчёте доказуемо.

## Область применения

Числа — «Общее число запросов» Яндекс Вордстата (поисковый спрос за 30 дней), это не охват
VK и не прогноз CPL; ориентир «15 000 запросов ≈ 10 000 аудитории VK» — практика оператора,
не гарантия. Замер идёт из залогиненной вкладки самого пользователя: капчу и вход агент не
проходит — просит пользователя. Бренды конкурентов добавляются только с явного согласия.
Широкие пласты добора (вклады, удалёнка и т.п.) в отчёте называются своими именами — решение
лить или резать остаётся за оператором.
