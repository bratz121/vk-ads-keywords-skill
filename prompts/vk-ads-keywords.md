---
description: Семантика VK Ads под тему до 15 000+ реальных запросов Вордстата (сам ресёрчит оффер и добирает пластами)
argument-hint: <тема/оффер, город> [цель, режим city|rf]
---

Задача: собрать ключевые фразы для VK Ads под названную тему — по категориям, с
минус-словами и реальной частотностью Яндекс Вордстата — и добрать объём до цели
(по умолчанию 15 000 запросов за 30 дней по региону).

Вход: $ARGUMENTS

Следуй методичке `AGENTS.md` из репозитория vk-ads-keywords-skill по шагам:
1. Бриф одним блоком вопросов (аудитория оффера; город или РФ; цель и куда льём; границы:
   широкие пласты, бренды конкурентов, свои бренды) — у каждого дефолт, «сам реши» = ехать
   на дефолтах. Затем ресёрч оффера в сети (что обещает, ЦА, похожие офферы и конкуренты).
   `KW init` с регионом и целью.
2. Подбор 15–40 фраз по 3–5 категориям (формулировки — из проб семян).
3. Замер: `KW js` → JS в залогиненной вкладке Вордстата → JSON в `inbox.json` →
   `KW record --in`. Нет своего браузера с логином — путь B: пользователь-курьер
   вставляет JS в консоль F12 сам и присылает JSON (`copy(...)` из `#kw-result`).
4. Чистка (2.1): аудит двойного смысла КАЖДОЙ фразы по её выдаче (`KW audit`);
   сомнение — против фразы; `rm`/`minus`/`checked`, затем `cleaned`.
5. Недобор → шаг 4: добор пластами по лестнице из `references/selection-rules.md`
   (ядро → тематический интерес → инструменты аудитории → события), каждый пласт с
   пробой и аудитом, замер после каждого. Бренды конкурентов — только с согласия.
6. Итог: `KW export`; в ответе — категории с числами, фразы блоками, минус-слова,
   что вычищено и почему, статус цели.

Если методички нет в контексте — сначала прочитай `AGENTS.md` (или попроси путь к нему),
затем работай по ней.

Жёсткие правила: числа только из выполненных замеров (чек-сумма ловит опечатки переноса);
капчу и вход в Яндекс не проходить — просить пользователя; шаги 1–3 не повторяются,
циклы живут только внутри шага 4; недобор называется честно, с числом и вариантами.
